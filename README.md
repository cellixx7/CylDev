# CylDev

Site vitrine para prospecção de dashboards, landing pages, cursos (Excel/Power BI) e SaaS.

Fluxo: Homepage → Hero → Entregas interativas (dashboard e landing ajustáveis) → Orçamento (mão de obra × tempo) → Contato.

## Rodar
```bash
npm install
npm run dev
```

## Personalizar
- `lib/config.ts` — WhatsApp, e-mail e redes sociais.
- `lib/pricing.ts` — serviços, horas base, multiplicadores e valor/hora.
